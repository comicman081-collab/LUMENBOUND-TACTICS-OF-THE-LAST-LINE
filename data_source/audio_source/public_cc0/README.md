# Public CC0 battle SFX sources

This directory contains unmodified source selections used to build the Web
runtime battle SFX pack. The project builder trims and converts copies under
`godot/assets/audio/sfx/public`; it never edits these masters.

All four source pages declare Creative Commons CC0 1.0 and permit commercial
use without required attribution. Creator credits are retained voluntarily for
traceability.

| Local directory | Source | Creator(s) | Use in this project |
|---|---|---|---|
| `free_firearm_sfx` | [The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library) | Ben Jaszczak, Brian Nelson, Kevin Heras, Matthew Nanney | 96 kHz/24-bit real firearm masters for pistol, rifle, shotgun, and burst starts |
| `bang_firework` | [25 CC0 bang / firework SFX](https://opengameart.org/content/25-cc0-bang-firework-sfx) | rubberduck | Real firework, cannon, bang, and short-shot recordings for explosions and card accents |
| `wood_metal` | [100 CC0 metal and wood SFX](https://opengameart.org/content/100-cc0-metal-and-wood-sfx) | rubberduck | Armor, boss-shell, and hard-surface hit layers |
| `various_impacts` | [Various Sound Effects](https://opengameart.org/content/various-sound-effects-0) | Julie Damsgaard / Spring Spring / Spring Enterprises | Bullet hit, player hit, and dull explosion layers |

License legal code: [Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode).

`Prepared Master Sheet.csv` is the metadata supplied with the Free Firearm
Sound Library. The source and runtime SHA-256 hashes are regenerated in
`reports/audio/AUDIO_LINEAGE_AUDIT.csv`.
