# Chapter 01 Script Outline

한국어 정본 JSON은 `data_source/scenarios/`에 있다.

1. `SCN_PROLOGUE`: 대정전과 기록 항해자의 각성, 첫 선택지.
2. `SCN_CH01_INTRO`: 등로단과 제7 승강장 구조 신호.
3. `SCN_CH01_MID_A`: 사람의 목소리를 흉내 내는 잔향체.
4. `SCN_CH01_MID_B`: 마지막 열차 행선지가 고의로 지워졌다는 발견.
5. `SCN_CH01_MID_C`: 종탑형 중계기의 생체 신호.
6. `SCN_CH01_PREBOSS`: 공허기관 각성, CH01-N10 연계.
7. `SCN_CH01_OUTRO`: 이동 피난처 좌표 복원과 다음 노선.
8. `SCN_REL_MAERU`: 빈 좌석 안전띠에 담긴 기억.
9. `SCN_REL_IRI`: 고장 난 안내 방송으로 만든 합창곡.
