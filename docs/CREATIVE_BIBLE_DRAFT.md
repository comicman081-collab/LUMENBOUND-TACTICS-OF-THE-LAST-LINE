# Creative Bible Draft

인물·지역 등 아직 잠기지 않은 고유명사는 `DEV 명칭`으로 관리한다. 게임 타이틀은 아래 정식 표기를 사용한다.

## 정식 타이틀 — LUMENBOUND: TACTICS OF THE LAST LINE

- 한글 음역이 필요한 경우에만 `루멘바운드`를 사용하며 타이틀 화면은 영문을 정본으로 한다.
- 타이틀 화면 표기: `LUMENBOUND` / `TACTICS OF THE LAST LINE`
- `랜턴라인`은 작품명이 아니라 세계관 내부의 광맥 철도망 명칭으로 사용한다.

- 세계: 대정전 이후 지하의 발광 광맥 철도가 고립된 거주구를 잇는다. 기억과 소리가 물질처럼 뭉치는 `잔광 폭풍`이 노선을 침식한다.
- 핵심 갈등: 이동 피난처의 행선지를 지운 세력과, 기억을 흉내 내며 증식하는 잔향체 사이에서 실제 기록을 복원한다.
- 주인공: 전투 지휘관이자 기록의 진위를 판별하는 `기록 항해자/길잡이(DEV)`다. 성별·연령을 유일성 장치로 삼지 않는다.
- 조직: `등로단(DEV)`은 구조·의료·노선 복구를 맡는 민간 기술 조직이다. 캐릭터가 싸우는 이유는 선로와 피난민을 지키기 위해서다.
- 적: 근접 잔향, 원거리 광점, 방어 껍질, 회복 메아리, 중계 프레임, 거대 공허기관으로 SD 실루엣과 역할을 명확히 나눌 수 있다.
- 정적 제작 적합성: 역·터널·기록실처럼 장면 단위 배경이 분명하고 감정 변화는 표정 교체와 조명 페이드만으로 전달된다.
- 확장성: 노선/정거장 하나가 챕터 하나가 되며 지상·해저·이동 피난처로 장기 확장 가능하다.
- 차별점: 학교/학생/교사 관계가 아니라 인프라 복구 조직과 이동 노선, 기억의 진위 문제를 중심으로 한다.

## 폐기 후보 B — 조수 보관소

- 세계: 수면이 계속 상승하는 군도에서 잠수 기록사가 침몰한 도시의 법적·문화적 기록을 회수한다.
- 갈등/주인공: 회수한 기록의 소유권을 둘러싼 부유 공동체 간 충돌을 중재하는 독립 감정사.
- 조직/적: 잠수 구조대가 압력 생물, 자동 방재기, 산호 기계와 싸운다.
- 제작/확장: 정적 수중 배경과 잠수복 실루엣이 경제적이며 수심대별 챕터 확장이 쉽다.
- 차별점: 전투보다 기록의 소유권과 공동체 합의가 서사의 중심이다.

## 폐기 후보 C — 기후 직조선

- 세계: 도시마다 날씨를 직조하는 거대 선박이 운항하며 고장 난 기후 직물이 생태계를 찢는다.
- 갈등/주인공: 한 도시를 살리면 다른 도시가 피해를 입는 자원 배분을 판단하는 항로 조정사.
- 조직/적: 수리 승무원이 폭풍 매듭, 번개 포자, 불법 기후 드론과 싸운다.
- 제작/확장: 날씨별 배경 교체가 강하고 항로마다 새로운 적 팔레트를 추가할 수 있다.
- 차별점: 학교도시/학생 부대 대신 기후 인프라와 자원 윤리가 중심이다.

## 선정 근거

`LUMENBOUND`는 빛에 결속된 원정대라는 파티 서사를, `TACTICS OF THE LAST LINE`은 턴 제한 이동·노선 탐험·전술 전투를 직접 전달한다. `랜턴라인`은 고유 철도망 명칭으로 분리해 `노선=챕터` 구조와 장기 세계관 확장성을 유지한다.
