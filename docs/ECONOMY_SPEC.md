# Economy Specification

작전력은 기본 120, 6분당 1을 실제 시스템 시각으로 복구한다. NORMAL 비용은 지정 공식을, HARD는 대응 비용 +6(최대 24)을 사용한다. 개발 모드는 소비/입장 제한을 우회하지만 일반 저장 규칙은 유지한다.

반복 보상은 주 재료 보장, 보조 35%, 희귀 8%이며 희귀 8회 실패 뒤 다음 1회를 보장한다. pity는 `stage:item` 키로 저장한다. 실제 전투와 소탕 모두 `RewardService.resolve`를 사용한다.

HARD는 스테이지별 로컬 날짜 기준 3회다. 서버 검증이 없는 오프라인 MVP이므로 시계 조작에 안전하다고 주장하지 않는다.
