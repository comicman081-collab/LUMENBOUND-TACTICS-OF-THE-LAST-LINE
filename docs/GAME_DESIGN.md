# Game Design

`LUMENBOUND: TACTICS OF THE LAST LINE`은 정적 일러스트 스토리와 5인 SD 실시간 자동전투를 잇는 장거리 탐험 SRPG다. `랜턴라인`은 대정전 이후 거주구를 잇는 세계관 내부 철도망의 이름으로 사용한다. 유료 뽑기·결제·광고·PvP·서버 계정은 포함하지 않는다.

핵심 루프는 `스토리 → 5인 편성 → 스테이지 전투 → 보상 → 레벨/돌파/스킬/공용 무기 성장 → 다음 스토리`다. 파티 슬롯은 전열 2, 중열 2, 후열 1이며 중복 캐릭터를 허용하지 않는다. 프리셋 5개가 저장된다.

버티컬 슬라이스는 캐릭터 8명, 적 11종, Chapter 1 NORMAL 10/HARD 5, 메인 스토리 7편, 개인 스토리 2편을 포함한다. 모든 수치와 콘텐츠는 `data_source` 정본에서 생성한 런타임 JSON으로 읽는다.

관계 레벨은 1~20이며 프로필/개인 스토리를 해금하지만 전투 능력치에는 직접 보너스를 주지 않는다. 캐릭터 획득은 기본/스토리/HARD 조각 인터페이스뿐이다.
