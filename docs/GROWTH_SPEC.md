# Growth Specification

캐릭터/계정 최대 레벨은 100, 무기는 60이다. 캐릭터 레벨은 계정 레벨과 B0~B5 상한 중 낮은 값을 넘지 못한다. 1~100 곡선과 경험치/크레딧은 정본 CSV에 전 행을 기록한다.

회귀 합계:

- 캐릭터 EXP 1→100: 905,520
- 캐릭터 크레딧 1→100: 412,400
- 무기 EXP 1→60: 144,330

돌파는 B0 20, B1 40, B2 60, B3 80, B4 90, B5 100 상한과 1.00/1.02/1.04/1.07/1.10/1.14 배율을 사용한다. B3 프로필, B5 승리 테두리 해금은 저장된다.

캐릭터마다 NORMAL 10, PASSIVE 10, ULTIMATE 5 레벨이다. 각 레벨 실수 배열과 정확한 비용이 `skills.json`, `skill_upgrade_costs.csv`에 있다. 공용 무기는 class 호환이며 전용 소유자 ID는 모든 데이터에서 빈 문자열이다.
