# Originality and IP Checklist

- No external game image is shipped.
- No reference face, hair, costume, weapon, emblem, pose trace, UI frame, name or story is reused.
- Pilot humans are original clearly adult women; enemies are nonhuman and genderless.
- ImageGen anchors were generated specifically for this project; Blender processing and source files are internal.
- Krea2 and paid external APIs were not used.
- Review references remain outside packaged artifacts.
- Production approval requires a final human originality review.
