# UI Visual Bible

Target UI combines dark translucent glass, restrained brass edge accents, cyan interaction highlights and a three-level Korean typography hierarchy. Panels, spacing, icon borders and button states must be consistent. Existing positions and hit regions remain stable.

R5 browser review found the story and battle imagery substantially ahead of title, home, formation, result and growth panels. Those screens remain DEV-style and are not visually approved. Portrait/icon integration and landscape-orientation guidance are mandatory for the next UI revision.
