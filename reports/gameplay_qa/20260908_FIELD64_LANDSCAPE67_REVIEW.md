# 지역 탐험 · 이야기 연결 · 가로 화면 최종 검증

## 반영
- 세로 기기에서는 가로 iframe을 90도 회전하여 화면에 채운다. 게임 숨김/정지, 회전 안내, 세로 중앙의 축소 화면을 사용하지 않는다. 가로 전환은 동일 프레임과 게임 상태를 유지한다.
- 작은 가로 화면의 이야기 인물/대화 배치를 좌우로 구성하고 제목과 본문 크기를 조정했다. AUTO/SKIP 글자 폭을 확보했다. 시작 화면의 오래된 1·2장 안내를 20개 노선 소개로 갱신하고 잘리는 중복 클릭 안내를 숨겼다.
- CH02~CH20에 기존 정본 갈등에 맞춘 현장 이벤트 38개, 보급품 19개, 전체 20지역 탐험 목적을 추가했다. 지형 변경 없이 기존 연결된 통행 칸을 사용한다.
- 후반 단서는 N04 첫 완료 이후에만 발견/해결할 수 있다. 발견하지 않은 이벤트, 재선택, 새로고침으로 중복 보상을 받을 수 없다. 회수 선택도 탐험 완료율에 반영한다.
- 지역 이동 메뉴에 목적, 완료 작전 수, 다음 작전, 미개방 조건을 표시한다.
- 주요 동료 접촉 작전을 필수 경로에 포함했다. CH10·CH16·CH18·CH20의 동료 행동 장면을 실제 첫 접촉 이후로 옮겼다. 1~5회 승리 합류 계약과 보상/성장 비용은 유지한다.
- public Release에서 UI 숨기기, DEV 전체 스킵, 원시 시나리오 ID, QA 명령 통로가 허용되지 않는다.

## 사용자 빌드 및 한계
최종 로컬 Release: builds/web_gameplay_qa_20260908_release67_release.
설치 manifest orientation=landscape. 최종 public 브라우저 증거는 release66_browser/release67_title.png와 release67_boot.png다. 같은 검증 폴더의 home.png는 실제 일반 이야기 화면이며 다음/로그만 표시되고 개발 버튼과 SCN ID는 없다. 최종 부팅에서 QA bridge=undefined, 내부 viewport=844×390 확인.
