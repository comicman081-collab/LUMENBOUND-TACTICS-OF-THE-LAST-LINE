# 성장 화면 개선 기록

사용자 요청 5번: 레벨업·스킬업 이해도 개선. 기존 장비·돌파·캐릭터 정보는 같은 화면의 별도 탭으로 제공한다.

- 보유/필요 재료·크레딧, 정확한 부족량, 실제 획득처를 실행 버튼 근처에 표시.
- 훈련 노트별 경험치·예상 레벨·기본 능력치 변화, 경험치만 쌓이는 경우와 계정/돌파 상한 안내.
- 일반/패시브/궁극기의 실제 적용 단위와 대상, 전후 수치 표시. 효과가 고정된 궁극기 8종은 기존 레벨을 보존하고 추가 재화 소비·추천 제외.
- 개별 강화 즉시 저장, 화면 내 결과와 실패 재시도 표시. 잠긴/존재하지 않는 캐릭터 mutation 거부.
- 기존 화면의 열 너비가 축소되어 한두 글자씩 줄바꿈되던 결함을 실제 GridContainer 배분에서 수정. 선택 상태, 반응형 여백, 스킬 아이콘 크기 보완.
