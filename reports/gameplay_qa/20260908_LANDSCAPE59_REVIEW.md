# 가로 전용 전환

사용자 2026-09-08 최종 지시: 세로 UI를 취소하고 가로로만 출력한다. 회전 안내/차단 메시지를 띄우지 않는다.

Godot 1920x1080 화면을 aspect=keep으로 고정하고, Shell·맵·기존 보정 경로의 레이아웃 입력을 동일한 가로 기준으로 통일했다. 세로 창에서는 같은 가로 화면을 여백 안에 표시한다. 회전 안내 노드를 생성하지 않는다. PWA 설정과 공개 패키징 검증도 landscape 기준으로 변경했다. 실제 PWA manifest 출력은 최종 Release 빌드에서 확인한다.

검증: 일반293/293, landscape59_browser/acceptance.json 13/13. 성장·스토리·맵 실화면에서 915x412 / 844x390 / 390x844 창 크기 변경, 시나리오와 맵 인스턴스·위치 유지, 안내 없음, 런타임 오류 없음. 실기기의 OS 회전 잠금은 이번 브라우저 실행으로 검증한 것이 아니다.
