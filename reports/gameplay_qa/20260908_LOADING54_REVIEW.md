# HD 로딩 개선 loading54

동일한 로컬 Web 전투를 3회 실행했다. 요청 수와 원본 해상도는 유지했다.

| 전투 | 수정 전 | 수정 후 |
|---|---:|---:|
| 최초 | 10.110초 | 4.292초 |
| 두 번째 | 7.378초 | 3.074초 |
| 세 번째 | 7.131초 | 2.699초 |

HTTPRequest 기본 읽기 크기 64KiB가 대형 PNG를 여러 프레임에 걸쳐 수신 처리하던 병목이었다. 두 HTTP 로드 경로에서 1MiB로 변경했다. 동시에 요청 3개, 페이지당 12MiB 제한, 프레임당 디코딩 1개, SHA256 검증, 64MiB 캐시를 유지한다. 브라우저 실제 파일 전송은 평균 약 20ms였고 PNG 디코딩보다 엔진 수신 처리 대기가 컸다.

검증: loading54_battle/acceptance.json 223/223, region_loading_runner 197/197, test_runner 293/293. 로컬 Chrome 결과이며 실기기/인터넷 환경의 시간을 보장하는 측정은 아니다. 기존 네이티브 일반 테스트의 자산 경고는 별개다.
