# 스토리 개발자 UI와 사용자 빌드 분리

첨부 화면은 개발자 모드 화면이다. `DEV 전체 스킵`과 `SCN_…` 시나리오 ID는 기존에도 개발자 전용이었다. `UI 숨기기`는 기존에 사용자 모드에도 표시됐으며 이번에 개발자 전용으로 수정했다.

- 사용자 모드: 다음·로그·AUTO·일반 SKIP 유지. 하단 개발자 버튼 두 개와 시나리오 ID 없음.
- 개발자 모드: UI 숨기기·DEV 전체 스킵·시나리오 ID 유지.
- 버튼 생성과 실제 함수 호출에 모두 개발자 권한 검사 적용. 사용자 모드로 스토리를 구성할 때 숨김 상태도 초기화.
- 사용자 세로 화면의 하단 버튼은 다음·로그 한 줄이며 빈 개발자 행이 생성되지 않음.
- 사용자 Release는 `--export-release` 및 개발자 custom feature가 없는 `Web HTML Release` 프리셋으로 생성. 저장 설정을 바꿔도 Release에 개발자 권한을 부여할 수 없음.

실제 컨트롤 생성·가로/세로·권한·함수 호출 검사 25/25, 일반 회귀 293/293 통과. 사용자 Release 로컬 빌드 성공. 브라우저에서 전체 캠페인을 다시 순회한 검증은 아니며 공개 배포는 수행하지 않았다.
