# 2026-09-10 로컬 실행 검사 및 수정

대상: 현재 미커밋 변경을 포함한 SD_STORY_RPG_GODOT 작업본. Godot 4.7.1 Stable Standard, Windows, 실제 Chrome WebGL 실행을 사용했다. 기존 작업을 되돌리지 않았으며 배포, 업로드, 외부 생성 API 또는 모델 실행을 수행하지 않았다.

## 수정한 실제 문제

1. **강화 직후 새로고침 시 마지막 저장 유실.** 기존 브라우저에서 일반 스킬 Lv.2 강화와 “저장 완료” 표시 후 즉시 새로고침하면 Lv.1로 복구되는 것을 재현했다. Godot 파일 쓰기는 완료되어도 IndexedDB 반영은 비동기다. 체크섬이 포함된 동기식 브라우저 복구 저널을 저장 완료 전에 기록하고, 재실행 시 검증한 최신 저널을 우선 복구하도록 수정했다. 기존 파일 저장과 백업, 마이그레이션 및 샌드박스 분리를 유지했다.
   - 수정 후 성장 검사: 스킬 레벨과 지불한 재료가 새로고침 후 정확히 일치.
   - 실제 브라우저 저장 공간 오류 주입: 완료 표시 금지, 추가 재료 차감 차단, 저장 재시도 시 중복 강화 없음, 재시도 직후 새로고침 복구 통과.
   - 근거: `browser_growth/acceptance.json`, `final_growth_clarity_audit/acceptance.json`, `final_save_persistence_audit/acceptance.json`.
2. **기본 Web 빌드에서 별도 HD 이미지 누락.** 개발/릴리스 빌드 및 R7 릴리스 경로에 `_hd/` 복사 단계가 없고, 기존 HTML 패키징은 모든 하위 폴더를 거부했다. 모든 경로에 별도 이미지 배치를 연결하고, 644개 이미지의 크기·SHA-256·파일 목록을 기록/검증하도록 수정했다. 패키징은 검증한 `_hd/`만 허용한다. 누락·변조·불완전한 원본·덮어쓰기 방지 회귀 검사 6개 통과.

## 바로잡은 검증 도구

- 부하 검사: 현재 게임이 투사체 24개, 피해 숫자 40개로 동시 표시를 제한하는데, 과거 테스트는 100개 동시 표시를 요구했다. 100개 요청을 두 번 가하면서 표시 제한, 만료 후 반환, 재사용 시 추가 할당 없음으로 검증하도록 수정했다.
- 화면 회전 검사: 실제 높이 337.5 CSS 픽셀을 정수 `clientHeight === 337`로 비교하던 오류를 수정했다. 실제 16:9 사각형과 브라우저의 0.5px 반올림을 검증한다.
- 오디오 검사: 가로 화면 규칙에 맞는 뷰포트를 사용하고, 맵 준비 후 늦게 나타나는 첫 작전 안내 및 전투 전 대화를 실제 입력으로 처리하도록 수정했다. 기존 오디오 검사 시도는 전투 진입 증거로 사용하지 않는다.
- `RUN_LOCAL_WEB.ps1` 추가: 설치된 실제 Python 실행 파일을 찾아 HD 파일 검증 후 localhost 서버를 실행한다. Windows Python 실행 별칭을 거쳐 종료된 시험 서버가 빈 응답을 반환했던 환경 문제는 새 서버의 HTTP 200 응답을 확인한 뒤 재검증했다.
