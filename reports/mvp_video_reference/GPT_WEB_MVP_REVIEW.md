# GPT Web MVP Review

검토 대상은 현재 R7 정본의 독립적인 장거리 SRPG 탐색 맵, 이벤트/스토리 진행, 기존 5인 실시간 SD 전투, 결과·성장·저장 복구 연결이다. 검토는 사용자가 지정한 기존 ChatGPT 인앱 브라우저 세션에서 수행했으며, 참고 영상 자체나 추출 프레임은 전송하지 않고 로컬 분석에서 추상화한 상호작용 문법과 현재 구현 증거만 전달했다.

## 외부 검토 판정

- 독립 IP 및 기존 실시간 전투 동결: PASS
- MVP 상태 전이 구조: PASS WITH P0 HARDENING
- 최신 Web N01/N10 실기동: UNVERIFIED
- 프로덕션 승인: WAITING_USER_APPROVAL

## P0 권고 및 반영 상태

1. 전투 결과의 모든 canonical mutation을 결과 커밋 경계에서 정확히 한 번 처리하고, 이후 스토리와 맵 공개는 presentation-only로 유지한다.
   - 반영: 결과 콜백에서 보상, 별, first clear, 적 제거, 위치, 저장을 완료한 뒤 결과 화면을 표시한다.
   - 반영: 신규 공개 연출은 `pending_reveal`/`reveal_consumed` one-shot 상태로 분리했다.
2. 전투 transaction ID와 exactly-once 경계를 명시한다.
   - 반영: `pending_encounter.token`, `processed_reward_tokens`, `processed_battle_tokens`를 사용한다.
3. 한 번의 실제 키/포인터 동작이 최대 한 번의 화면 전이를 일으키도록 edge/debounce/echo 방어를 둔다.
   - 반영 진행: Story/transition 입력 경계 테스트와 함께 보강한다.
4. 새로고침 복구 경계를 검증한다.
   - 스토리: 저장된 scenario checkpoint에서 복구.
   - 전투 준비/진행 중: live simulation을 직렬화하지 않고 전투 전 맵 좌표로 안전 복구; 적 유지, 보상 미지급.
   - 결과 커밋 이후: canonical 진행은 저장됐고 보상 재지급 금지.
   - 공개 연출: 미소비 상태는 한 번 유지, 소비 후 재생 금지.
5. N10 프리보스 시나리오는 전투를 직접 시작하지 않고 N09 인접 staging 위치로 복귀한 다음 실제 N10 적 접촉으로만 진입한다.
   - 반영 및 맵 회귀 테스트 완료.

## P1 권고

- 보스 PHASE_2/ENRAGE 배너는 상태 이벤트당 한 번만 표시하고 3배속에서도 판독 가능하게 유지한다.
- 타이틀/전투 준비 연출은 짧게 유지한다.
- 결과 화면은 핵심 보상과 새로 가능한 성장에 우선순위를 둔다.
- 신규 경로 공개 연출은 실제 신규 공개가 있을 때만 한 번 표시한다.

## 금지 권고

- 전투 확인 팝업을 이중으로 추가하지 않는다.
- 모든 조우마다 장시간 스토리를 강제하지 않는다.
- QTE·스와이프·별도 보스 시뮬레이션을 만들지 않는다.
- 레퍼런스 UI를 복제하지 않는다.
- 같은 결과에 대해 여러 전체화면 보상 창을 겹치지 않는다.
- 복잡한 mid-battle 저장을 MVP 범위로 확장하지 않는다.
- 스토리 스크립트가 BattleScene을 직접 호출하지 않는다.

## 외부 검토가 요구한 Web 수락 시나리오

1. N01 전체 흐름과 맵 복귀.
2. 결과 커밋 직후 새로고침해도 보상 중복 0.
3. 포스트 스토리 중 새로고침해도 진행·스토리 플래그 유지.
4. Enter/Space/클릭/터치 입력 edge 중복 전이 0.
5. N09→프리보스→N09 staging→N10 실제 접촉.
6. N10 PHASE_2/ENRAGE 시각 이벤트.
7. N10 결과 커밋 후 새로고침.
8. 맵 위치·적·보물·공개 상태 복구.

이 문서는 외부 의견 기록이며 자체 테스트를 대체하지 않는다. Web 실기동 증거가 완료되기 전에는 N01/N10과 전체 MVP를 PASS로 승격하지 않는다.
