# 2026-09-11 로컬 플레이 수정 및 검증

실행: http://127.0.0.1:8770/play/471e2adea4a9/

실행기: 프로젝트 루트의 `START_LOCAL_GAME.cmd`. 최종 빌드는 `builds/web_feedback_20260911_player_final`이며 `Web Local Player` 프리셋으로 내보냈다. 기존 실제 저장 네임스페이스와 8770 포트를 유지한다. 브라우저 검사는 별도의 `qa=...` 저장 공간에서 수행했다.

## 변경

- 프롤로그 하단 대화창의 최소 높이 증가 방향을 위로 변경했다. 선택지 두 개가 화면 밑으로 밀려나지 않는다.
- 지도 선택 객체를 초기화할 때 공유된 원본 보물/노드 사전을 비우던 참조 오류를 수정했다. 보물을 획득하면 보상 창이 뜨기 전에 지도 오브젝트와 미니맵 표시가 사라진다.
- 적 턴에는 시야 안에서 이동하는 적을 순서대로 따라간 뒤 아군에게 돌아오도록 카메라 연출을 연결했다.
- 기존 선형 경로도를 실제 지형 기반 미니맵으로 교체했다. 더블클릭/연속 두 번 터치로 전체 지도를 열며, 방문·관측한 지역만 나타난다. 미탐색 구역 및 숨은 보상/적은 표시하지 않는다. 전체 지도에 한글 테마를 적용했다.
- 아군 5명을 왼쪽 절반에 아래–위–아래–위–아래로 배치하고 축소했다. 일반 적·정예·보스의 크기는 원화의 머리/발 기준으로 정규화하여 확대했다. 보스 위치에는 우측 화면 여백을 확보했다.
- 로컬 플레이 프리셋이 고해상도 전투/맵/효과 에셋을 읽도록 연결했다. 로컬 호스트에서만 적용되며 개발자 기능은 활성화하지 않는다. 기존 이미지 원본이나 에셋 승인 상태를 바꾸지 않았다.
- 웹 BGM을 브라우저 AudioBuffer 재생으로 분리하여 Godot 화면 처리/리소스 로딩에 따른 끊김을 줄였다. 다음 곡의 디코딩이 끝날 때까지 현재 곡을 유지하고 0.22초 동안 교차 전환한다. 같은 곡 요청은 재시작하지 않는다.
- 기존 90초 WAV 네 곡 끝의 약 10~11초 무음을 루프 메타데이터에서 제외했다. 원본 음악 파일 바이트는 보존했다. 데스크톱 교차 전환의 중간 음량 하락도 선형 진폭 전환으로 수정했다.
- 전투 일시정지 중 화면 크기가 바뀌면 기존 일시정지 메뉴를 함께 제거하고 다시 만든다. 이전에는 HUD만 제거하여 일시정지 메뉴가 중복될 수 있었다.

## 유지한 결과와 검증 범위

1080p·50초 인트로, 약 0.292초 오버랩, 기존 BGM과 소스 영상 음성 제거 결과는 변경하지 않았다. OGV/MP4 해시가 이전 완료본과 일치한다. `final_hashes.json`에 최종 PCK 및 WASM 해시도 기록했다.

이번 작업은 기존 HD 원본의 실제 로딩 및 표현을 수정한 것으로, 몬스터 원화를 새로 생성한 작업은 아니다. 109개 전체 전투 에셋의 연결을 검사했지만 모든 캐릭터·보스의 모든 모션을 개별 육안 심사한 것은 아니다. 물리 휴대폰 검사는 수행하지 않았다. 온라인 배포나 GitHub Actions는 실행하지 않았다.

브라우저 로그에서 출처 URL이 없는 Electron 주입 스크립트의 MutationObserver 예외 1건이 관측되었다(`player_browser_exceptions.json`). 게임 소스/HTML의 예외로 확인되지 않았으며 실제 게임 진입·전투·복귀를 막지 않았다. 모든 브라우저 콘솔이 무오류였다고 주장하지 않는다.

중간 r2/r3 캡처 중 결과 화면, 미확대 지도, 뷰포트 변경 시 잘린 캡처는 디버깅 기록으로 남겼다. 위에서 지정한 검증 캡처를 사용한다.

## 재개 시 실행기 복구

8773번 이전 QA 주소가 열려 있었고 8770번 플레이 서버도 종료된 상태를 확인했다. START_LOCAL_GAME.ps1의 숨겨진 자식 프로세스 실행을 WMI의 숨겨진 독립 프로세스 생성으로 교체했다. 로그는 프로젝트 reports/local_launcher 안에 기록하며, Python은 -B로 실행한다. 실행기가 종료된 뒤에도 HTTP 200을 반환하고 서버의 부모가 WmiPrvSE.exe인 것을 확인했다. 실행기를 다시 호출했을 때 동일한 PID를 재사용하는 것도 검사했다. 게임 빌드와 저장 네임스페이스는 바뀌지 않았다. 증거: launcher_independent_process.json.
