- 타이틀·기지·동료: 제목과 시작 버튼을 분리하고, 기지를 자체 제작 일러스트와 시설 버튼으로 구성했다. 캐릭터 상세는 전신 원화와 성장 정보로 나눴다. 새 메뉴 이름에 맞춰 첫 방문 안내도 수정했다.
- 성장: 목표 레벨을 선택하면 보유 훈련 노트를 자동 조합한다. 비용 미리보기와 실행 시 재검증을 적용하고, 남는 경험치는 보존한다. 재료를 하나씩 고를 필요가 없다.
- 대화·보상·결과·로딩: 선택지와 대화창을 화면 안에 배치하고, 일반 대화의 진행 버튼을 아래에 고정했다. 보상 수량은 줄바꿈하지 않으며 확인 버튼은 고정했다. 로딩창은 실제 화면 중앙에 배치했다. 전투 HUD와 결과 화면 하단 버튼의 줄바꿈·잘림을 수정했다.
- 첫 지도 안내: 별도로 남아 있던 큰 글자와 과도한 여백을 수정했다. 작은 창에서도 3단계 본문 전체가 표시되고 확인 버튼과 겹치지 않는다.
- 지도 진행: 보상 후 선택 객체를 원본에서 지우던 참조 오류, 보상 후 적 턴 재개 잠금, 접촉 처리가 실제 전투를 요청하지 않았는데도 이동을 끝내던 경로를 수정했다. 해금되는 적의 웹 표시를 다시 연결했다.
