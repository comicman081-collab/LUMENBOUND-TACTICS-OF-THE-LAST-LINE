# 지도 외형 2단계 + 전투 규모감 (2026-09-30)

요청: "2단계 진행해"

- 방향 문서: `reports/visual_direction_20260930/VISUAL_DIRECTION.md`의 2단계(A1 재질, A3 원경, A5 UI 정리, A6 표식, B1·B2 이동 동작, B4 조우 전환)를 1장 기준으로 적용하고, 색은 생물군계 8종으로 넓혔다. 1단계에서 넘긴 D7 규모감도 했다.
- 지도 규칙(이동력, 시야, 적 턴, 접촉), 지형 데이터, 전투 계산은 그대로다. 모두 화면 연출 변경이다.
- 참고 영상의 그림이나 UI는 가져오지 않았다. 표식과 패널은 모두 코드로 그렸다.

## 구현 항목

| 항목 | 내용 | 파일 |
|---|---|---|
| A1 재질 | 지형 셰이더를 다시 썼다. 상면: 바닥색 칸에만 이끼·눈·모래 얼룩, 칸 가장자리 마모와 홈. 절벽: 지층 띠, 턱 밑 이끼 띠, 아래로 갈수록 어두워짐. 계단식 높이 계산과 메시는 그대로다 | `chapter_map/shaders/terrain_surface.gdshader` |
| A1 생물군계 색 | 숲·서리·사구·재·해안·유리·월면·폐허마다 얼룩·마모·턱·대기 색. 새 텍스처 없이 같은 셰이더를 쓴다 | `chapter_map/view/region_palette.gd` (`surface_look`) |

| A5 UI 정리 | 데스크톱: 행동 버튼을 화면 아래 막대로, 부제 숨김, 얇은 상태 줄. 안내 문구는 화면 위 짧은 알림(토스트). "탐험 N%"는 "탐사율" 원형 게이지로. 미니맵 접기 버튼. 세로·좁은 화면은 기존 상단 배치와 세로 보정 스크립트를 그대로 쓴다 | `chapter_map_screen.gd`, `chapter_map/ui/exploration_gauge.gd`, `app_shell.gd` |
| A6 표식 | 보스 해골, 정예 별, 사건 "!", 보물 상자가 칸 위에 떠서 맥박처럼 깜빡인다 | `chapter_map/ui/map_presentation_overlay.gd` |
| B1 파티 토큰 | 한 칸마다 포물선 도약(평지는 작게, 높이차가 있으면 크게), 착지 먼지. 이동 속도와 칸 판정 시점은 그대로다 | `chapter_map_screen.gd` (`_move_along`, `_set_pawn_hop`) |
| B2 경로 미리보기 | 빛나는 행진 점선, 화살촉, "N칸" 배지(이번 턴에 못 가는 칸은 회색, "N칸 / M"). 이동 범위 테두리를 따라 도는 빛. 기존 3D 경로 리본은 반투명 가이드로 낮췄다 | `map_presentation_overlay.gd`, `chapter_map_screen.gd` |
| B4 조우 전환 | 일반 조우: 카메라가 접촉 칸으로 밀고 들어간 뒤, 속도선 와이프와 적 정보 패널(웨이브별 적 이름·수, 권장 Lv, 부대 평균 Lv)이 옆에서 들어오고 전투 로딩으로 넘어간다(1.35초, 패널이 뜬 뒤 탭하면 넘김). 보스는 기존 BOSS 띠, 이벤트 접촉과 "전환 줄이기" 설정은 기존 경로 | `godot/ui/encounter_wipe.gd`, `app_shell.gd` |

| D7 다음 웨이브 | 다음 웨이브를 적 구역 뒤에 붉은 테두리 실루엣과 "NEXT WAVE ×N"으로 대기시킨다. 보스 등장 중과 마지막 웨이브에는 없다 | `battle_view.gd` |
